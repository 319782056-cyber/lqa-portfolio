# 刘庆安 · 经营数据分析作品集

面向数据分析师、经营分析师和数据运营岗位的互动作品集。通过模拟经营数据，展示从指标定义、数据拆解、经营分析到异常识别和情景测算的分析思路。

## 在线模块

- 经营总览：核心 KPI、近 6 个月趋势、目标达成率和经营观察
- 产品分析：产品销量排名、门店分布、关键词筛选和 CSV 导出
- 门店分析：门店销量、区域归属、日均销量和贡献占比
- 区域分析：区域销量、门店数量、贡献结构和分析提示
- 数据质量：异常规则示例、处理状态和数据质量说明
- 销售预测：保守、基准、乐观三种情景测算及口径说明

## 数据边界

当前版本使用内置脱敏模拟数据，不包含企业内部原始数据，也不连接任何外部业务系统。

- 重新生成模拟数据只会在当前页面会话中刷新演示数据。
- 数据质量模块中的异常是规则示例，不代表真实监控告警。
- 销售预测是基于日均销量的简单情景外推，不是训练和回测后的预测模型。
- 页面中的门店、品牌、产品、销量和增长率均为虚构演示数据，不应作为真实经营结论引用。

后续在获得授权后，可以逐步加入脱敏案例，并为每个案例补充数据来源、字段口径、清洗规则、分析方法和业务建议。

## 技术栈

- React 19
- Vinext / Vite
- TypeScript
- Cloudflare Workers

## 本地运行

需要 Node.js 22.13 或更高版本。

    npm install
    npm run dev

## 检查与构建

    npm run lint
    npm test
    npm run build

## 发布

项目使用 Cloudflare Worker 运行。部署前请确认 Cloudflare 环境变量、资源绑定和域名配置均已准备好。

    npm run deploy

自定义域名：lqa.ccwu.cc（以 Cloudflare 实际配置为准）。
