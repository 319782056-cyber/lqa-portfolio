# 刘庆安 · 经营数据分析作品集

面向数据分析师、经营分析师和数据运营岗位的互动作品集。以虚构的连锁茶饮经营场景为载体，展示指标体系、数据拆解、经营诊断、利润测算、用户分析、库存策略、渠道转化和情景预测等分析能力。

## 分析工作台

### 经营分析基础模块
- **经营总览**：核心 KPI、近 6 个月趋势、目标达成率和自动生成的经营观察
- **产品分析**：产品销量排名、售卖门店覆盖、关键词筛选、明细展开和 CSV 导出
- **门店分析**：门店销量、区域归属、日均销量、贡献占比和模拟环比
- **区域分析**：区域销量、样例门店数量、贡献结构和分析提示
- **数据质量**：异常规则示例、处理状态和质量风险说明
- **销售预测**：保守、基准、乐观三种情景测算及模型边界说明

### 进阶经营分析模块
- **利润分析**：销售额、折扣、净收入、商品成本、毛利率、营销费用和经营利润估算；拆解单杯经济模型
- **用户分析**：估算订单与购买用户、客单价、复购率、用户生命周期分层和用户价值指标
- **库存分析**：销量速度、库存覆盖天数、安全库存、再订货点和补货建议
- **渠道分析**：外卖、到店自取、堂食收入结构，以及从流量到支付订单的转化漏斗

## 指标与数据口径

- 销量单位为杯；日均销量 = 统计周期销量 ÷ 统计天数。
- 产品、门店、区域贡献占比按各自演示权重分配，权重总和按 100% 设计。
- 目标达成率 = 当期销量 ÷ 演示目标值。
- 利润分析中的售价、折扣、商品成本、营销费用率和门店运营成本均为假设参数；利润估算不包含税费、平台佣金、租金差异、人工、损耗及总部费用。
- 用户分析中的订单杯数、用户覆盖系数、复购率和生命周期参数为假设值，不代表真实会员行为。
- 库存覆盖、库存结构和补货点由销量及假设天数推算，不代表真实仓储数据。
- 渠道份额和漏斗转化率是演示参数，不代表真实埋点数据。
- 销售预测使用日均销量外推和情景系数，不是经过训练、验证和回测的统计预测模型。

## 数据边界与使用说明

当前版本使用内置虚构模拟数据，不包含企业内部原始数据，也不连接任何外部业务系统。

- 重新生成模拟数据只会在当前页面会话中刷新演示数据。
- 数据质量模块中的异常是规则示例，不代表真实监控告警。
- 页面中的品牌、产品、门店、销量、价格、成本、用户和渠道指标均为虚构或假设演示数据，不应作为真实经营结论引用。
- 所有进阶分析用于展示分析框架和计算思路。真实项目应先完成数据授权、数据字典、指标口径评审、异常处理和模型回测。

## 技术栈

- React 19
- Vinext / Vite
- TypeScript
- Cloudflare Workers

## 本地运行

需要 Node.js 22.13 或更高版本。

    npm install
    npm run dev

## 检查与构建

    npm run lint
    npm run typecheck
    npm test
    npm run build

## 发布

项目使用 Cloudflare Worker 运行。部署前请确认 Cloudflare 环境变量、资源绑定和域名配置均已准备好。

    npm run deploy

自定义域名：lqa.ccwu.cc（以 Cloudflare 实际配置为准）。
