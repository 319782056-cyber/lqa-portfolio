# 刘庆安 · 全自动经营数据看板作品

这是一个用于面试展示的互动经营数据看板，演示从数据更新、质量检查到经营分析和异常处理的完整使用流程。

## 在线功能

- 自动任务与更新确认
- 品牌与月份经营总览
- 产品销量排名及门店明细
- 门店销量排名及产品明细
- 区域经营对比
- 自定义产品看板
- 异常监控与处理状态
- 月底销量情景预测
- CSV 数据导出

## 数据说明

页面使用经过脱敏和模拟处理的演示数据，不包含企业内部原始数据。自动更新、异常处理和预测交互用于展示产品设计与网页实现能力。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

## 发布

项目使用 Cloudflare Worker 运行，推送到 GitHub 后可由 Cloudflare 自动构建与发布。

- 构建命令：`npm run build`
- 发布命令：`npx wrangler deploy --config dist/server/wrangler.json`
- 自定义域名：`lqa.ccwu.cc`
